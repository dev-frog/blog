# ReconForce-01.1

Today we are doing **_hackNos: Recon Force (V1.1)_** VM from Vulnhub. It was designed by Rahul Gehlaut of hackNos series. It is Easy to Intermediate Box. Let’s start.

## 1. Scanning

To see what services are running in the box we use “nmap” to find out.

```bash
nmap -sV -sC -oA scan 192.168.0.7
```

**![nmap scan](https://lh6.googleusercontent.com/lvRPnS_1w20oXpbR4mq8yEGsmhcOOVQxixkfA-IXFZmSb6mqiUVTkvNezLSdPFELzUR7V8RkA5Li8UcA0iVgKaL768N3fHTPR_cBXLb-p606I0LC0RNTCXY2TLLmwkLMOBRSZ0_P)**

So we got 3 open ports and It’s running on Ubuntu. We decided to start from 80 ports.

## 3 Hidden Directory

To find out the hidden folder we use **dirb**, this tool gets the hidden folder and files name from the server with status code.

```bash
dirb http://192.168.0.7
```
